**Blasé Plaza Archives — REPLIT BUILD PROMPT**

Build a full-stack web application called **Blasé Plaza Archives**. The app pulls real permit and planning data from Miami-Dade County, identifies commercial plazas scheduled for demolition or major renovation within the next 1–5 years, and formats each one as a formal field survey report.

---

**DATA SOURCES**

Pull from the following Miami-Dade public APIs. All are free and require no authentication for basic queries.

**1. Demolition Permits — Miami-Dade Open Data (Socrata)**
```
https://opendata.miamidade.gov/resource/rbng-6mha.json
```
Filter for:
- `permit_type = 'DEMOLITION'`
- Occupancy types: `MERCANTILE`, `BUSINESS`, `RETAIL`
- Issue date within the last 5 years OR expiration date in the future

**2. Building Permits for Major Renovation**
```
https://opendata.miamidade.gov/resource/rbng-6mha.json
```
Filter for:
- `permit_type = 'BUILDING'`
- `work_description` contains keywords: `DEMOLISH`, `TOTAL DEMOLITION`, `RENOVATION`, `REDEVELOPMENT`, `REBUILD`
- Occupancy types: `MERCANTILE`, `BUSINESS`, `RETAIL`
- Issue date within the past 2 years

**3. Miami-Dade GIS Parcel Data**
```
https://gisws.miamidade.gov/arcgis/rest/services/MDC_Landuse/MapServer/0/query
```
Use this to enrich permit records with parcel size, land use classification, and zoning. Query by address or parcel ID from the permit record.

**Geocoding:** Use the Miami-Dade GIS geocoder to convert addresses to lat/lng for map pins:
```
https://gisws.miamidade.gov/GisAddress/GisAddressService.svc/rest/findAddressCandidates
```
Or fall back to the free OpenStreetMap Nominatim geocoder:
```
https://nominatim.openstreetmap.org/search?q=[ADDRESS]&format=json&limit=1
```

Refresh all data once daily and cache results in Supabase. Each unique commercial property with an active permit = one survey entry.

**TIMELINE CLASSIFICATION**

Each plaza entry should be classified by demolition/renovation horizon based on permit data:

- **IMMINENT (0–1 year):** Active demolition permit issued, not yet expired
- **NEAR-TERM (1–3 years):** Building permit for demolition/redevelopment issued, under review, or recently approved
- **PROJECTED (3–5 years):** Renovation permit filed, or parcel zoned for redevelopment with active permit activity

Display this classification prominently on each report card and map pin.

Use this system prompt for the Claude API call:

*"You are a field surveyor for Blasé Plaza Archives, a project that documents commercial plazas and strip malls in Miami-Dade County before they are demolished or renovated.

**API KEY SYSTEM**

Build a simple API key generation and validation system stored in Supabase.

**Supabase table — `api_keys`:**
```
id            uuid, primary key
key           text, unique — a randomly generated 32-character alphanumeric string
label         text — a name the user gives their key (e.g. "My Research Project")
email         text — contact email of the requester
created_at    timestamp
last_used_at  timestamp
is_active     boolean, default true
request_count integer, default 0
```

**Key format:**
```
BPA-XXXXXXXXXXXXXXXXXXXXXXXXXXXX
```
Prefixed with `BPA-` followed by 28 random alphanumeric characters. Example:
```
BPA-k7mN2pQr9xLvT4wYcD8sJhA3nF6b
```

**Authentication:**
All API requests must include the key in the request header:
```
X-BPA-API-Key: BPA-k7mN2pQr9xLvT4wYcD8sJhA3nF6b
```
If the key is missing, invalid, or inactive, return:
```json
{
  "error": "UNAUTHORIZED",
  "message": "A valid API key is required. Request access at [app URL]/api-access"
}
```
with HTTP status `401`.

On every successful authenticated request, update `last_used_at` and increment `request_count` in the Supabase table.
